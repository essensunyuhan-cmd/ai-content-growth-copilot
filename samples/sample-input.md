# Sample Input

> Synthetic example for public demonstration. It does not contain private company or user data.

## Product introduction
A consumer decision-support app that helps users compare historical transaction information and understand product / market data before making a decision.

## Target user
Users who are making a high-value purchase decision and want more evidence before trusting an asking price or sales recommendation.

## Core selling points
- historical transaction information
- structured comparison
- data-assisted decision support

## User feedback
1. “I can see the asking price, but I don't know whether it is reasonable.”
2. “Different agents give me different answers. I want something I can verify myself.”
3. “I want to know how similar items were actually transacted before.”
4. “I'm worried the market is changing, but I don't know what data I should look at.”
5. “I want some evidence before I negotiate.”

## Operation goal
Help target users understand the product's decision-support value and increase high-quality product visits.

- Xiaohongshu
- Douyin
